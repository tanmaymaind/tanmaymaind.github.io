# Tanmay Maind — Portfolio

A premium luxury-style personal portfolio website in black & gold: hero with portrait,
about, experience, skills, featured projects, certifications, YouTube channel, and contact.

## View it locally

Open `index.html` in any browser — no build step, no dependencies.

## Publish with GitHub Pages

1. Push this folder to a GitHub repository (for a personal site URL, name the repo
   `tanmaymaind.github.io`).
2. Repository **Settings → Pages → Build and deployment → Deploy from a branch**,
   branch `main`, folder `/ (root)`.
3. The site goes live at `https://tanmaymaind.github.io/` (or
   `https://tanmaymaind.github.io/<repo>/` for any other repo name).

## Files

- `index.html` — all page content (edit text, projects, and links here)
- `styles.css` — black & gold luxury theme
- `script.js` — footer year + mobile menu
- `profile.jpg` — hero portrait (LinkedIn profile photo)
- `.nojekyll` — tells GitHub Pages to serve files as-is
